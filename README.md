# Calculator Hub

A scientific calculator, unit converter, and personal finance calculator
suite (SIP, SWP, loans, retirement, FD/RD, gold, bonds, buy-vs-rent, and more)
built with React, TypeScript, and Vite.

## Run locally

**Prerequisites:** Node.js (v18 or higher)

1. Install dependencies:
   ```
   npm install
   ```
2. Start the dev server:
   ```
   npm run dev
   ```
3. Open the URL shown in the terminal (usually http://localhost:3000)

## Build for production
```
npm run build
```
The output goes to the `dist/` folder, ready to deploy to any static host
(Vercel, Netlify, Cloudflare Pages, GitHub Pages, etc.)
